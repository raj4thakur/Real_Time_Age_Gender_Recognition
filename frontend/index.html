About VisionAge AI

This project demonstrates an end-to-end computer vision pipeline using a web interface, FastAPI backend and trained Keras deep learning models.

  • Real-time webcam processing
  • Deep learning based prediction
  • FastAPI inference API
  • Lightweight browser interface

How it works

The webcam captures frames periodically. Each frame is sent to the FastAPI backend, where it is preprocessed and passed through the trained age and gender recognition models.

  • Webcam captures a frame
  • FastAPI receives the image
  • Keras models perform inference
  • Prediction is returned as JSON
